# Analytics Copilot 2

Analytics Copilot 2 is an ADK-based agent designed for bank staff to perform natural language data analytics on BigQuery data (operational tables and analytical views).

## Commands

```bash
# Run CLI
agents-cli run "Give me month on month view of credit card transacted customers"

# Start Playground
agents-cli playground

# Run Evaluations
agents-cli eval run

# Add Deployment
agents-cli scaffold enhance . --deployment-target agent_runtime
```
